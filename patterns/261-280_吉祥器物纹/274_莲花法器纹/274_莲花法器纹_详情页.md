# 274 莲花法器纹｜Lotus Ritual Object Pattern

## 一句话简介
莲花与法器组合成纹，常见于宗教陈设和礼仪装饰，寓意清净、庄严与护佑。

寓意清雅、祥瑞、护佑、威仪、圆满。

## 纹样释义
清净、护佑、庄严、圆满

## 纹样构成
通常由中心莲花、莲座、法轮、宝瓶、宝伞、香炉、飘带、珠链和祥云组成。法器围绕主莲花对称展开，以圆形或纵向轴线组织，垂饰与云气连接不同层级。

## 现代应用
适合用于宗教文化礼盒、香文化品牌、展陈主视觉、织物、首饰和空间装饰。现代设计可保留中心莲花与少量代表性法器、减少器物数量、避免构图过于繁密。
