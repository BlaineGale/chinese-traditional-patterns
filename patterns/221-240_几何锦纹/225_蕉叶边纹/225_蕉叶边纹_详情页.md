# 225 蕉叶边纹｜Plantain Leaf Border Pattern

## 一句话简介
蕉叶形单元连续展开成边饰，多见器物肩部边缘，寓意舒展生机与雅致。

寓意生机、连绵、清雅、自然。

## 基础信息
- 中文名：蕉叶边纹
- 英文名：Plantain Leaf Border Pattern
- 拼音：jiāo yè biān wén
- 分类：几何锦纹
- 流行年代：传统器物装饰中长期使用，瓷器肩部与颈部装饰尤为常见。
