# 227 花草边纹｜Floral Grass Border Pattern

## 一句话简介
小型花草连续成带，适合作为细腻边饰，寓意繁盛柔美与和谐生长。

寓意生机、圆满。

- 中文名：花草边纹

- 分类：几何锦纹
