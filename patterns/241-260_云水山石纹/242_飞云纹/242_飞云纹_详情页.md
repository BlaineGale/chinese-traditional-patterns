# 242 飞云纹｜Flying Cloud Pattern

## 一句话简介
飞动云带形成纹样，具有轻盈速度感，寓意飘逸、祥瑞与自由。

寓意祥瑞、升腾。

- 中文名：飞云纹
- 英文名：Flying Cloud Pattern

- 流行年代：汉唐以来云气纹持续演变，唐宋及明清装饰艺术中常见流动飞云形态。

- 视觉特征：云带细长舒展，速度感明显、方向性强，常呈斜向或横向飞动、云头与尾线衔接流畅、留白较多，画面轻盈、整体飘逸、灵动、富有节奏
- 适合配色：淡青、米白、浅金、青绿、暖白、青灰、白色、古金、靛蓝、金色

## 纹样释义
飘逸、祥瑞、自由、升腾、轻盈

## 纹样构成
通常由细长云带、卷曲云头和尾部流线组成。多个云形单元可沿统一方向排列，也可上下错落、相互穿插，形成连续飞动结构。

## 现代应用
动态品牌线条、包装背景、服饰飘带纹样、网页动效、展览导视、新中式插画
